# Security reports

For reproducible launcher problems without sensitive details, open a bug-report issue.

For a vulnerability involving private data, malicious imported files or credential exposure, use the repository's **Report a vulnerability** option if the maintainer has enabled private reporting. If that option is unavailable, ask XHYN_PH for a private reporting route through the community channel before posting technical details. Do not publish sensitive material in the public Telegram group or a public issue.

Include the affected version, minimal reproduction and impact. Do not attach real signing keys, account credentials, full game directories or unrelated personal files.

No security-response deadline or independently audited security status is claimed for this community project. The current maintenance target is the latest published community revision.
