INSTALLATION AND TROUBLESHOOTING

1. Back up your saves and close any other GTAV app.
2. Install revision 8 over the purple-icon revision 7 and open XHYN V.
   No uninstall is needed. Saved preferences, layouts and imported drivers
   stay in the existing com.xhynph.v installation.
   The optional Drivers page imports driver ZIPs or restores bundled Turnip.
3. Grant the existing game-folder access prompt.
4. Use the existing Games/GTAV data folder and allow time for the first shader
   cache build. Run only one GTAV app at a time.

An older revision 5 app, if still installed, shares the external game folder
with this app. Run only one at a time. Revision 8 updates revision 7 in place;
Android normally prevents installing a lower-version APK as an update.

If a problem occurs, collect these files from Games/GTAV before launching
another build, which may rotate or overwrite shared logs:
- gtav_driver_test2.log
- gtav_tty.log
- The newest gtav_exit_trace_*.bin
- Any newly generated gtav_pipeline_error.log and associated .spv files

Include the device model, Android version, stage reached, and time before the
failure. If gtav_driver_test2.log is missing, include that detail in the report.
