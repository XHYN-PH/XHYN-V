# XHYN V 0.10 — Controls and renderer customization

**By XHYN_PH 🇵🇭**

This update adds portable control pages, a shortcut wheel, more graphics choices and optional advanced renderer configuration. It keeps the native libraries and update identity from revision 9.

## Highlights

- Optional floating movement stick and left-handed camera zones.
- Eight-slot keyboard/mouse shortcut wheel.
- Up to eight control pages per mode, included in exported profiles.
- Visual profile gallery and touch starter layouts.
- Reversible individual detail settings, custom FPS, VSync and compiler workers.
- Optional DXVK queue tuning, environment editor and global `dxvk.conf` support.
- Effective-settings preview and launcher/custom configuration precedence.
- Moveable app statistics HUD and local CPU/RAM/thermal report export.
- Five menu languages; sliders snap in steps of ten.

## Installation

Close the game and back up saves before updating. Revision 10 installs over revision 9 using the same package `com.xhynph.v` and signing identity. Retain existing profiles/settings; no uninstall is required for that upgrade path.

Use the APK attached by the maintainer when available. GitHub's generated repository archives contain documentation and do not install on Android. Compatible game data is supplied separately and is not part of the repository.

## Status and limits

17,473 host assertions and package/signature checks passed. The nine native libraries match revision 9. XHYN_PH reported gameplay on earlier versions using Snapdragon 8 Gen 3 / Adreno 750, Android 16, 12 GB RAM; **0.10 phone confirmation is pending**.

FPS values are limits, not performance promises. The report exporter records app CPU/RAM/thermal statistics, not game FPS/GPU/frame-time telemetry. DXVK version switching, LSFG-VK/frame interpolation and Winlator profile import are not included.
