# XHYN V 0.10 — Controls and renderer customization

**By XHYN_PH 🇵🇭**

This update adds portable control pages, a shortcut wheel, more graphics choices and optional advanced renderer configuration. It keeps the native libraries and update identity from revision 9 (private).

## Highlights

- Optional floating movement stick and left-handed camera zones.
- Eight-slot keyboard/mouse shortcut wheel.
- Up to eight control pages per mode, included in exported profiles.
- Visual profile gallery and touch starter layouts.
- Reversible individual detail settings, custom FPS, VSync and compiler workers.
- Optional DXVK queue tuning, environment editor and global `dxvk.conf` support.
- Effective-settings preview and launcher/custom configuration precedence.
- Moveable app statistics HUD and local CPU/RAM/thermal report export.
- Five menu languages; sliders snap in steps of ten.

## Installation

When updating close the game and back up saves before updating. Retain existing profiles/settings; no uninstall is required for that upgrade path.

Use the APK attached. Compatible game data is supplied separately and is not part of the repository.

The full installation guide and changelog are available in the repository at `docs/INSTALLATION.md` and `CHANGELOG.md`.
