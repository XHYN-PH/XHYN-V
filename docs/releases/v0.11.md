# XHYN V 0.11 — Input tools and local management



Revision 11 expanded the control tools and local management features while keeping all nine native libraries from revision 10 unchanged.

## Added and refined

- Input testing without engine startup; combinations, double tap, long press and temporary alternate bindings.
- Configurable quick toolbar, icons/colors, menu accent/text size and Simple/Advanced views.
- Creator mode with optional watermark and a restore handle.
- Applied/pending settings status, driver cache manager and free-space display.
- Timestamped save backups, retention, restore preview, verified recovery and ZIP export.
- Selective support ZIP export with captured-content previews.
- Less unnecessary overlay polling and fewer temporary allocations in active-touch drawing.

## Scope at this revision

Swappy was deferred and not present in 0.11; it was included in [0.12](v0.12.md). FSR/spatial upscaling and frame interpolation were not implemented. Renderer version selection arrived in [0.13](v0.13.md).
