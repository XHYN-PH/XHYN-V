# XHYN V 0.12 — Control refinements and native pacing

## Highlights

- **Launcher home** closes gameplay and returns to the launcher; save in-game first.
- Russian and French join the existing menu languages.
- Button fading, groups/position locks, editor zoom/pan, larger touch areas and directional swipes.
- Linear/Precision/Acceleration touch mouse curves.
- Reversible population/distance settings where the runtime's XML provides them.
- Tiler/texture-bias experiments and explanations of active override sources.
- Complete setup profiles with all four touch modes, graphics, driver references and renderer settings.
- Optional compiled Swappy pacing and Android performance hints, both Off by default.

## Native behavior and limits

The Vulkan loader gained presentation and hint integration; eight other original native libraries stayed unchanged. Unsupported pacing/hint paths retain normal rendering. Pacing does not generate frames, and hints do not force clocks or bypass thermal policy.

Revision 12 still used the original bundled DXVK pair. Four selectable pairs arrived in [0.13](v0.13.md). Spatial FSR/upscaling and frame interpolation are not installed features.
