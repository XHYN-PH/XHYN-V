Save and close gameplay, select a version, then launch in a fresh process. Keep your working driver while comparing DXVK versions. GPLAsync can make objects appear late; return to 3.1+ if an alternative causes problems.

**Prepared build · Revision 13 · By XHYN_PH 🇵🇭**

Revision 13 adds four integrated DXVK choices while retaining the existing launcher, controls, graphics restoration and native presentation experiments. The original **DXVK 3.1+** remains the default.

## Included renderers

| Choice | Description |
| --- | --- |
| DXVK 3.1+ | Original bundled pair, unchanged from r12 |
| DXVK 2.7.1+ | Compatibility pair adapted from the supplied comparison APK; complete source provenance unavailable |
| DXVK 2.7.1 GPLAsync | Android ARM64 build with optional asynchronous shaders |
| DXVK 1.10.3 Native | Experimental Android ARM64 legacy port with narrower option/interface support |

Select through **Drivers → Choose DXVK version** or **Graphics → Advanced renderer**. Save before closing gameplay, then start a fresh process. These are native matched pairs; arbitrary Windows DXVK DLL imports and hot swapping are not supported.

## Integration changes

- Validate alternative payload sizes/hashes and repair damaged extracted copies from the APK.
- Preload matching DXGI/D3D11 libraries before the engine, including restored-activity launch paths.
- On library-load failure, choose 3.1+ for the next restart without mixing a partially loaded pair.
- Separate renderer/driver caches and preserve the existing default cache location.
- Include DXVK/async preferences in complete setup exports, with migration of older profiles.
- Filter unsupported legacy tuning/HUD selections while retaining saved preferences for compatible versions.
- Record selected/loaded renderers in diagnostics and translate the new selector across seven languages.

All nine original r12 native libraries remain byte-identical, including the engine, original DXVK, SDL, driver, input helper and Vulkan loader. Alternative pairs are added as private assets.

## Status and limits

XHYN_PH reports that the current revision works very well on the stated Snapdragon 8 Gen 3 / Adreno 750, Android 16, 12 GB RAM setup. The report does not identify the selected DXVK/driver or confirm each alternate pair and optional feature separately.

Build validation records **23,674 host Java assertions**, including 67 renderer checks, plus Android native compilation/linking, interface/dependency/alignment and package/signature checks. No controlled physical-device FPS, battery, thermal or XHYN V-versus-Winlator benchmark was performed by that validation.

GPLAsync can cause objects to appear late during compilation. Legacy 1.10.3 has unsupported Windows-specific interfaces and fewer tuning/HUD options. Library-load fallback cannot catch every later GPU crash. Swappy/hints remain opt-in experiments, and frame interpolation/spatial upscaling remain absent. See [renderer details](../ADVANCED_RENDERER.md).

## Update and rollback

Close the game, back up needed data and install the signed 0.13 APK over the matching r12 package. The package/signing identity is retained. To roll back a renderer experiment, fully close the app, select 3.1+ and the known working driver, then launch again. Reinstalling an older APK is a separate Android version/signature issue; renderer rollback does not require it.

Public downloads, when published, appear on [Releases](https://github.com/XHYN-PH/XHYN-V/releases). This document describes the prepared build and does not imply a 0.13 release asset has already been uploaded.
